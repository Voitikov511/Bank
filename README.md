# БанкПлюс

Сайт банка на Python Flask.

## Учетные записи

- Сотрудник: `employee` / `employee123`
- Клиент: `client` / `client123`

## Запуск

```bash
pip install -r requirements.txt
python app.py
```

Адрес сайта: `http://127.0.0.1:5000`

## Особенности

- стандартный дизайн банка;
- версия для слабовидящих с высоким контрастом и крупным шрифтом;
- карта сайта;
- страница 404;
- новости;
- поиск;
- форма сообщений;
- заявки на банковские продукты;
- роли пользователей.
